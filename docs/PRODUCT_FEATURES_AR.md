# ميزات QAMZOR الإضافية — تقرير التنفيذ

هذه الوثيقة تفرّق بين محرك Python وواجهات Kotlin ومزايا Android. مصدر QZRA 1.3 في Kotlin وواجهته على Android أُضيفا، لكن نجاح Gradle/JUnit وبناء APK واختبار الجهاز ينتظر تشغيل GitHub Actions. الموصلات السحابية أدناه متاحة في Python CLI/Core ولا يوجد تسجيل دخول/مزامنة سحابية في Android حتى الآن.

## الموجود سابقًا

| الميزة | الحالة | التفاصيل |
|---|---|---|
| إخفاء بيانات الأرشيف | منفذة في QZRA 1.3 | تشفير Manifest وإخفاء عدد العناصر |
| حماية المجلدات | منفذة في QZRA 1.3 | كلمة مرور مستقلة لكل نطاق مجلد، حتى 32 نطاقًا |
| الاسترداد | منفذ | ملفات `.qzrec` باستخدام XOR parity؛ إصلاح كتلة تالفة واحدة في كل مجموعة |
| إزالة التكرار | منفذة | إعادة استخدام الكتل داخل الأرشيف وكائنات SHA-256 بين اللقطات |
| المشاركة الآمنة | منفذة | توقيعات Ed25519 منفصلة والتحقق منها |

## المضاف في هذه الدفعة

### Smart Exclusions — الاستثناءات الذكية

- `--exclude PATTERN` لتجاوز ملفات أو مجلدات أثناء الإنشاء.
- `--exclude-from FILE` لقراءة قائمة أنماط UTF-8.
- دعم `.qzignore` في المجلد المحدد والمجلدات المتداخلة.
- الأنماط السالبة التي تبدأ بـ`!` غير مدعومة وتُرفض صراحةً.

مثال:

```bash
qz create backup.qzra ./Project --exclude '*.tmp' --exclude 'build/'
```

### Background Job Center — مركز المهام

واجهة Python `JobCenter` تشغّل إنشاء الأرشيف في عدد محدود من العمال، وتعرض التقدم وتدعم الإيقاف المؤقت والاستئناف والإلغاء عند نقاط آمنة بين الكتل. تُحفظ حالة المهمة دون كلمات مرور، والمهام التي كانت نشطة عند إغلاق العملية تتحول إلى `interrupted` بدل استئناف غير آمن تلقائيًا.

في Android تُشغّل عمليات إنشاء الأرشيف والاستعادة والفحص والنسخ الاحتياطي وفحص/استعادة النسخ وعمليات WebDAV عبر WorkManager مع إشعار Foreground. تعرض شاشة العمليات النسبة والبايتات والسرعة والوقت المتبقي، وتدعم الإيقاف المؤقت/الاستئناف التعاوني والإلغاء عند نقاط تقدم آمنة. يحافظ WorkManager على العمل المجدول بعد إغلاق Activity وإعادة تشغيل الجهاز؛ إذا قُتلت عملية التطبيق أثناء التنفيذ، تعيد المهمة المعاملة من البداية ولا تستأنف من آخر بايت.

### Split Archives — تقسيم الأرشيف

```bash
qz split backup.qzra ./volumes --part-size-mib 100
qz join ./volumes/backup.qzra.qzset restored.qzra
```

يُنشئ ملفات أجزاء ووصف `.qzset`، ويتحقق من SHA-256 لكل جزء ومن الملف بعد إعادة التجميع قبل نشر الناتج. الحد الأدنى لحجم الجزء 1 MiB. البصمات تكشف التلف العرضي، لكنها لا تمنع مهاجمًا من استبدال الأجزاء والوصف معًا؛ استخدم توقيع Ed25519 ومفتاحًا عامًا موثوقًا للتحقق من المصدر.

### Archive Compare — مقارنة الأرشيفات

```bash
qz compare old.qzra new.qzra
```

تعرض العناصر المضافة والمحذوفة والمتغيرة والثابتة وفق المسار والنوع والحجم وبصمة SHA-256 المسجلة في Manifest. المقارنة لا تقرأ كل Payload؛ شغّل `qz verify` عند الحاجة إلى فحص بيانات الأرشيف نفسها.

### Advanced Preview — معاينة مستندات Office

```bash
qz preview backup.qzra Project/report.docx --office
```

يدعم استخراج النصوص من DOCX وXLSX وPPTX بحدود لحجم الملف وعدد عناصر ZIP وحجم فك الضغط ونسبة الضغط. هذه معاينة نصية وليست عرضًا مطابقًا لتنسيق Microsoft Office؛ لا تدعم الماكرو ولا تعرض التخطيطات والرسوم والمحتوى المضمن كاملًا.

### Cloud Backup — WebDAV وموصلات المزودين

```bash
qz cloud push backup.qzra --url 'https://dav.example.net/dav/QAMZOR/' --username USER
qz cloud pull backup.qzra restored.qzra --url 'https://dav.example.net/dav/QAMZOR/' --username USER
```

يتطلب خادم WebDAV متوافقًا وبيانات دخول. يستخدم HTTPS، وملف بيانات جانبيًا بالحجم وSHA-256، وتنزيلًا مؤقتًا لا يُنشر إلا بعد التحقق. الاختبار المحلي استخدم خادم WebDAV تجريبيًا على loopback؛ لم يتم اختبار مزود سحابي خارجي. أضيفت الآن موصلات REST فعلية إلى Google Drive API v3 وDropbox API v2 وMicrosoft Graph OneDrive وAWS Signature V4 لـS3/S3-compatible في Python Core/CLI. تستخدم Access Tokens/مفاتيح تُمرر وقت التشغيل عبر متغيرات البيئة، وتدعم رفع الجلسات/الأجزاء، وملف SHA-256 جانبيًا، وتنزيلًا مؤقتًا يتحقق قبل النشر. موصل S3 يدعم multipart حتى سقف QAMZOR الحالي 1 TiB. لم تُختبر الاتصالات مع حسابات خارجية فعلية لعدم توافر بيانات اعتماد المستخدم. Android يوفّر الآن حسابات WebDAV عبر HTTPS ورفع/تنزيلًا متحققًا ومزامنة يدوية ثنائية الاتجاه لأرشيفات QZRA في جذر مجلد واحد. واجهات OAuth الأصلية لمزودي Drive/Dropbox/OneDrive/S3 غير متاحة بعد في Android. ملف SHA-256 ليس توقيعًا مقاومًا لتلاعب خادم يقدر على استبدال الملف والوصف معًا؛ استخدم توقيع Ed25519 ومفتاحًا عامًا موثوقًا.

## نتائج التحقق المحلي

- 90 اختبار Python ناجح (بالإضافة إلى 9 subtests).
- `python -m compileall -q src tests tools` ناجح.
- بناء Wheel باستخدام backend المثبت محليًا ناجح.
- تثبيت Wheel في مجلد منفصل واستيراد الحزمة والتحقق من واجهات الميزات ناجح.
- اختبارات WebDAV أجريت على خادم loopback محلي، وليست اختبارًا لخدمة سحابية خارجية.

## ما لم يُنقل بعد إلى التطبيقات

QZRA 1.3 موجود في Kotlin Core مع اختبارات interop. Android UI يربط كلمات مرور النطاقات المستقلة في الإنشاء والاستعادة والفحص والمقارنة، ويعرض البحث والترتيب وإصدار QZRA وتقسيم/تجميع الحِزم. أضيفت واجهات Android للنسخ الاحتياطي المحلي المجدول والإصدارات وخزنة كلمات المرور ومفاتيح التوقيع وWebDAV وUSB/SD ومركز العمليات الخلفية. تظل Smart Exclusions وOffice preview وموصلات Drive/Dropbox/OneDrive/S3 وظائف Python Core/CLI. واجهة Android تدعم WebDAV فقط. لا تعتبر النسخة مكتملة على الأجهزة قبل نجاح GitHub Gradle CI والاختبار الفعلي.
